# Birthday Box — Advanced Edition

## Included
- Multi-photo upload and previews
- Personalization: name, message, mood and optional music upload
- Animated mystery gift box
- Cinematic slideshow with timeline, captions and clickable thumbnails
- Confetti effects
- Candle-blowing interaction with microphone support where permitted, plus tap fallback
- Final birthday message
- Fully client-side; no server required

## Run
Open `index.html`, or run:
```bash
python -m http.server 8000
```

## Host
Recommended: Netlify Drop, Vercel, or GitHub Pages. Upload the folder containing `index.html`.

- Built-in original birthday soundtrack generated in-browser with Web Audio API
